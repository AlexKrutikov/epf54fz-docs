# Внешняя обработка «Работа с кассой»

Данная обработка предназначена для проведения на подключенном к
конфигурации фискальном регистраторе таких операций «Внесение»,
«Выплата», снятие кассовых отчетов «Х-отчет», «Z-отчет», «Отчет о
состоянии расчетов», «Отчет о регистрации», а также выполнения операций
открытия и закрытия смены.

Обработку «Работа с кассой» можно использовать, открывая через пункт
меню «Файл» - «Открыть», либо добавить во внешние обработки, либо
встроить в конфигурацию и вывести в пункт меню или на панель
инструментов.

При открытии обработки открывается следующее окно, содержащее Главное
меню:

![](/images/image109.png)

В поле «Фискальный регистратор» необходимо выбрать подключенную модель
кассы, с которой будут выполняться операции через данную обработку, в
противном случае операции выполняться не будут.

Кассовые операции

В разделе «Кассовые операции» пользователю доступны следующие операции
на кассе:

Внесение, Выплата, Чек коррекции и Менеджер чека.

![](/images/image110.png)

Внесение -- операция внесения наличных денежных средств в ККМ.

Выплата -- операция изъятия наличных денежных средств из ККМ.

Чек коррекции -- предназначена для вызова формы для пробития чека
коррекции

(подробнее о пробитии чека коррекции см. раздел «Чек коррекции» данной
инструкции).

«Менеджер чека» - Вызывает окно менеджера чека, для пробития чека не из
формы документов кассовых ордеров. Используется для пробития операции
чека «Отгрузка без оплаты (в кредит)»

Для возврата в главное меню необходимо нажать кнопку «Назад».

Кассовые отчеты

![](/images/image111.png)

В разделе «Кассовые отчеты» доступны следующие отчеты:

1\. Х-отчет -- кассовый отчет без гашения.

2\. Z-отчет -- кассовый отчет с гашением. Если организация пробивает
чеки из документов «Приходный кассовый ордер», «Расходный кассовый
ордер», «Оплата от покупателя платежной картой» и не пользуется
документом «Чек ККМ» для пробития чеков, то для закрытия смены
необходимо пользоваться именно этим пунктом.

3\. Отчет о состоянии расчетов - Данный отчет нужен для того чтобы
выяснить, все ли фискальные данные были переданы в ОФД.

4\. Отчет о регистрации -- отчет с информацией о последней проведенной
регистрации ККТ.

5\. Копия последнего документа и копия последнего чека -- одинаковые
операции использующие разные методы драйвера. Предназначена для печати
копии последнего чека.

Кассовая смена

![](/images/image112.png)

Данный раздел необходим для проведения операций с кассовой сменой, а
именно её открытие и закрытие. При этом имеется возможность производить
программное открытие и закрытие смены для обновленных конфигураций,
имеющих в своем составе документ «Кассовая смена».

Для включения возможности проведения программного открытия и закрытия
кассовой смены, необходимо в настройках обработки обслуживания на
закладке «Дополнительно» установить флаг «Производить программное
открытие/закрытие смены».

Для открытия смены необходимо выбрать кассу организации в поле «Касса
ККМ» и нажать на кнопку «Открытие смены». При этом на кассовом аппарате
будет распечатан отчет об открытии смены. Если в настройках обработки
обслуживания ККМ был установлен флаг «Производить программное
открытие/закрытие смены», то так же создастся и документ «Кассовая
смена» с состоянием «Открыта», после чего можно начинать работу с
кассовым аппаратом.

Для проведения операции «Закрытие смены» необходимо выбрать дату
закрытия, кассу организации в поле «Касса ККМ». Для обновленных
конфигураций также необходимо выбрать документ «Кассовая смена» со
статусом «Открыта» в поле «Смена» для проведения процедуры программного
закрытия смены. Т.е., другими словами, выбираем кассовую смену, которую
открыли в начале работы с кассой. Попытки выбора уже закрытой кассовой
смены будут блокироваться.

Для старых конфигураций, не имеющих в составе документ «Кассовая смена»
поле «Смена» заполнять не требуется.

Далее следует нажать на кнопку «Закрытие смены» и произойдет процедура
закрытия кассовой смены.

Флаг «Только смена статуса Кассовой смены» предназначен для проведения
процедуры смены статуса документа «Кассовая смена» на «Закрыта» без
снятия Z-отчета на ККМ (например когда Z-отчет уже снят на ККМ).

Для выхода из обработки необходимо вернуться в Главное меню обработки и
нажать кнопку «Выход».
