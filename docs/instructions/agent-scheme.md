# Работа по агентской схеме (по агентским договорам)

![](/images/image121.png)

Начиная с релиза ФЗ.54.08.11 обработка поддерживает работу по договорам
агента. Для активации данного функционала необходимо в параметрах
обработки перейти на закладку «Признаки агента» и в разделе «Реквизиты
агента» добавить в таблицу необходимое количество агентских договоров.

При добавлении нового договора откроется окно, в котором необходимо
указать нужный признак агента и заполнить агентские реквизиты

![](/images/image122.png)
![](/images/image123.png)

После заполнения необходимых или требуемых реквизитов агента необходимо
нажать кнопку «ОК» и данные по введенным реквизитам попадут в таблицу с
реквизитами агента. Так же данные реквизиты станут доступны для выбора в
таблице распределения реквизитов агента. Для последующего изменения
введенных реквизитов, необходимо два раза кликнуть левой кнопкой мыши по
нужной строке реквизитов и в открывшемся окне «Реквизиты агента» внести
необходимые правки.

Для применения введенных реквизитов агента к пробиваемым товарам
необходимо в разделе настроек «Распределение реквизитов агента» добавить
привязку товара к определенным реквизитам агента, по аналогии как это
делается в настройках Разделения чеков по СНО. При этом, в отличие от
функционала разделения по СНО, по договорам агента не происходит
разделение одного чека на несколько, а используется следующий алгоритм
отражения реквизитов в чеке:

Если все товарные позиции в чеке принадлежат к одним и тем же реквизитам
агента, то основные признаки агента и поставщика устанавливаются в целом
на чек. Если же в одном чеке присутствуют товары как собственные, так и
агентские, то установка реквизитов агента происходит для каждой позиции
в чеке и только на те позиции, которые принадлежат к той или иной
агентской схеме.
