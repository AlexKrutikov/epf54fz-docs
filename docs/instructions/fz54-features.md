# Особенности работы с обработкой ФЗ.54

1.  **Формирование чеков ЕНВД.**

В настройках кассы ККМ, должно быть **отключено** формирование
нефискальных чеков.

2.  **Шаблоны чеков в 1С Розница.**

В конфигурации 1С Розница существует возможность формирования шаблонов
кассовых чеков.

![](/images/image86.png)

Для корректной работы данных шаблонов в параметрах шаблона необходимо
отключить опцию "Не выводить фискальные строки на каждую позиции"
(галочка должна быть снята).

![](/images/image87.png)
