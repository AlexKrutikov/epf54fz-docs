# Работа по сети через службу RPC

> **Данный вариант доступен при установке компонента «Сервер удаленных
> подключения ККТ» из комплекта поставки драйвера ККТ АТОЛ версии 10.**

Если одну и ту же кассу необходимо использовать с разных рабочих мест в
одной локальной сети (либо распределенной сети, связанной через
VPN-каналы связи), но ККМ при этом не располагает Ethernet портом, то
для осуществления возможности совместного использования такой ККМ её
необходимо подключить по USB в один из компьютеров в локальной сети,
который будет являться главным по отношению к этой ККМ, а все остальные
компьютеры будут обращаться к ККМ посредством главного компьютера.

При установке драйвера ККТ Атол версии 10 на условный сервер (ПК с
подключенной кассой) необходимо установить флаг «Сервер удаленного
подключения ККТ», для того чтобы появилась возможность удаленного вызова
процедур и функций драйвера и других компьютеров.

![](/images/image17.png)

Сервер удаленных подключений использует порт 19524 для приема входящих
подключений. Порт должен быть открыт и не заблокирован брандмауэром.

В случае такого сетевого использования ККМ в окне настроек связи с ККМ
необходимо указать IP Адрес или DNS имя главного компьютера, к которому
подключена ККМ. В качестве порта связи с ККМ при этом необходимо выбрать
именно тот COM-порт, который используется и на главном компьютере для
связи с ККМ.

Т. е. если на главном компьютере ККМ определилась на порт COM1, то и на
всех остальных компьютерах необходимо указывать порт связи COM1.

Указание адреса сервера осуществятся в «Персональных настройках
подключения для драйвера ККТ», переход к которым осуществляется по
гиперссылке на первой странице параметров обработки.

![](/images/image18.png)

В поле Адрес СУД: необходимо указать IP адрес ПК с подключенной ККТ.
Таймаут подключения устанавливается в одноименном поле параметров и по
умолчанию составляет 10000 миллисекунд (10 секунд).

Подробнее о схемах подключения и использования сервера RPC от Атол можно
ознакомиться по ссылке: <https://integration.atol.ru/api/#rpc-server>
