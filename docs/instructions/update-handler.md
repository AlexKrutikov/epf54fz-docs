# Обновление обработки обслуживания

В случае, если получения обновление обработки обслуживания и
необходимости произвести обновление уже ранее загруженной в конфигурацию
обработки предыдущих версий, необходимо произвести следующие действия:

Сперва необходимо закрыть все окна, использующие подключенное торговое
оборудование (формы документов ЧекККМ, Приходный и расходный кассовые
ордера, Оплата от покупателя платежной картой, журналы кассовых
документов, форма регистрации продаж).

В режиме Предприятия открыть меню Сервис - Торговое оборудование --
Подключение и настройка торгового оборудования (доступно в полном
интерфейсе).

В открывшемся окне перейти на закладку «Фискальные регистраторы».

![](/images/image10.png)

Выделить в списке подключенную модель фискального регистратора, для
которой требуется произвести обновление обработки обслуживания. Нажать
на кнопку «Обработки обслуживания» и выбрать пункт -- "Обновить
обработку обслуживания для «Имя вашего устройства»".

![](/images/image11.png)

Далее откроется карточка обработки обслуживания, в которой необходимо
нажать на кнопку «Открыть» (пиктограмма с папкой), выбрать файл с новой
версией обработки обслуживания ККМ.

![](/images/image12.png)

После выбора файла в карточке обработки обслуживания её необходимо
записать, нажав на кнопку «ОК». Далее перейти в окно настройки
параметров обработки обслуживания нажатием на кнопку «Параметры»,
установить настройки новых параметров согласно разделу «[Настройка
параметров обработки](#настройка-параметров-обработки.)» данной
инструкции (это необходимо для инициализации возможных новых параметров
новой версии обработки) и сохранить настройки обработки кнопкой «ОК»

![](/images/image13.png)

![](/images/image14.png)

После всех этих действий необходимо перезапустить программу 1С.

> !!! Если в данной базе данных подключены ещё кассы через данную
> обработку обслуживания, либо одна ККМ подключена к разным рабочим
> местам через данную обработку, то обновить обработку обслуживания
> необходимо только один раз на одном из компьютеров, а настройку
> параметров и перезапуск 1С произвести на всех рабочих местах,
> использующих данную обработку обслуживания ККМ. Только соблюдение
> этого порядка обновления гарантирует стабильную работу обработки после
> процесса её обновления.

На этом процесс обновления обработки завешен.
