# Установка обработки обслуживания

## Каким видом подключать кассу

Начиная с версии 6.0 обработка умеет работать двумя видами оборудования: привычным
«Фискальный регистратор» и новым «ККТ с передачей данных». Вид, которым обработка
зарегистрируется, задаётся **именем файла** — конфигурация запоминает его в момент загрузки
файла в справочник обработок обслуживания и потом не переспрашивает.

| Файл | Каким видом регистрируется |
|---|---|
| `KKT_v.6.0.0.epf` (маркер `KKT` или `ККТ`) | ККТ с передачей данных |
| `FR_v.6.0.0.epf` (маркер `FR` или `ФР`) | Фискальный регистратор |
| имя без маркера | видом, выбранным в базе ранее; в новой базе будет задан вопрос при загрузке |

Маркер распознаётся в начале имени или после знаков `_`, `-`, `.`, и сразу за ним должен идти
такой же знак либо конец имени. Регистр букв значения не имеет. Например, `KKT_v.6.0.0.epf` и
`epf54fz-ккт-6.0.0.epf` дадут вид ККТ, а `KKTFR_v6.0.0.epf` не даст ничего: маркер в таком имени
не выделяется.

В одной базе можно держать оба вида одновременно — это нужно, когда парк касс переводится
на новый режим постепенно. Для этого файлы `KKT_*` и `FR_*` загружаются в **разные** элементы
справочника обработок обслуживания.

::: tip Перевод кассы из одного режима в другой
Вид у уже заведённого элемента справочника меняется переимпортом: загрузите в тот же элемент
файл с нужным маркером, и вид перечитается из файла. Само устройство при переводе нужно
пересоздать — удалить из записи прежнего вида и добавить на модель нового.
:::

::: warning Почему вид лучше задавать именем файла
У файла без маркера вид берётся из настройки, а она в конфигурациях без специального регистра
сведений хранится в стандартном хранилище 1С — то есть **отдельно для каждого пользователя**.
Выбранный администратором вид другому пользователю не виден, и при загрузке файла без маркера
вид у него определится заново. Маркер в имени файла от пользователя не зависит.
:::

Какой вид получила обработка, всегда видно в её настройках, на закладке «Настройки подключения»:
поле «Вид подключения», а под ним — пояснение, откуда этот вид взялся. Если вид задан маркером,
поле не редактируется.

## Порядок установки

**Установка обработки обслуживания осуществляется стандартным способом
(с помощью мастера настройки):**

1. Скопировать обработку обслуживания в любой каталог на жестком. 

2\. [Подключение обработки к 1С]. В режиме Предприятия
открыть меню Сервис - Торговое оборудование - Помощник подключения и
настройки торгового оборудования.

![Меню сервис](/images/image3.png)

3\. В открывшемся мастере нажимаем кнопку «Далее», выбираем тип
устройства — **Фискальный регистратор** или **ККТ с передачей данных**, в зависимости от того,
каким видом подключается касса (см. раздел выше). Тип должен совпадать с маркером в имени файла,
который будет выбран на шаге 5.

![](/images/image4.png)

 

4\. На шаге выбора обработки обслуживания выбрать вариант \"Добавить
новую обработку обслуживания\"

![](/images/image5.png)

 

5\. Далее выбрать вариант \"Из каталога\" и указать каталог, в который
была скопирована обработка на шаге 1.

![](/images/image6.png)

 После чего нажимаем на кнопку \"Получить список\", а затем кнопку
Далее.

![](/images/image7.png)

6\. Выбираем модель оборудования, кассу, к которой будет привязан
подключаемый фискальный регистратор.

![](/images/image8.png)

7\. В следующем окне устанавливаем параметры подключения фискального
регистратора.

![](/images/image9.png)

Нажимаем кнопку \"Тест связи\" и в окне сообщений будет выведена
информация о подключенном фискальном регистраторе.
