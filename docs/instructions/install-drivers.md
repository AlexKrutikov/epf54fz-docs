# Установка драйверов для работы с ККТ

**Для работы с ККТ АТОЛ** установить комплект драйверов Атол, который
можно скачать по ссылке:
[http://fs.atol.ru/SitePages/Центр%20загрузки.aspx](http://fs.atol.ru/SitePages/Центр%20загрузки.aspx?raz1=Программное+обеспечение&raz2=ДТО)

**Рекомендуется к использованию драйвер версии 10.X.X. Старый драйвер
версии 8 устарел и не дорабатывается производителем ККТ.**

Необходимо скачать драйвер ККМ Атол версии 10.10 (или выше).

![](/images/image1.png)

Распаковать скачанный архив и из каталога \\installer\\exe запустить
установочный файл драйвера.

> **Для 32х битной платформы устанавливать:
> KKT10-10.6.0.0-windows32-setup.exe, для 64х разрядной платформы
> устанавливать KKT10-10.6.0.0-windows64-setup.exe.**

Если планируется работа с ККТ через Веб-сервер Атол, то при установке
драйвером необходимо отметить флажком соответствующий пункт. При этом на
компьютере должна быть установлена Java такой же разрядности, что и
разрядность устанавливаемый драйверов.

![](/images/image2.png)

> **Важно! Если работа с ККТ будет вестись ТОЛЬКО через Веб-сервер, то
> разрядность платформы 1С и разрядность веб-сервера могут не
> совпадать.**

**Для работы с ККТ ШТРИХ** установить драйвера ККМ от компании ШТРИХ-М
версии 5.X, которые можно скачать по ссылке:
<https://optposcenter.ru/file-storage/folder2481/#ftop> .

Актуальная версия драйверов Штрих на 19.08.2025 от компании ККТЛаб -
5.19.1097.

Актуальная версия драйверов Штрих на 19.08.2025 от компании ПОСЦентр -
5.20.1130.

Установить драйвера Штрих со стандартными параметрами, нажимая далее в
процессе установки. По окончании установки драйвера Штрих, установить и
настроить связь ККМ с ОФД (данный процесс для ККМ Штрих мы не будем
рассматривать в рамках данной инструкции).

**Для ККТ Меркурий от компании Инкотекс** необходимо скачать и
установить службу INECRMAN по ссылке:
<https://www.incotexkkm.ru/support/inecrman> . Актуальная поддерживаемая
версия: 1.13.0.707.

**Для ККТ ВикиПринт от компании Дримкас** необходимо скачать и
установить VikiDriver по инструкции на сайте производителя:
<https://help.dreamkas.ru/kb/vikidriver/ustanovit-vikidriver/>
