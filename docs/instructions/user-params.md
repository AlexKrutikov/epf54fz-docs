# Установка параметров пользователя для работы с ККМ

Для работы с фискальным регистратором в конфигурации 1С необходимо так
же установить параметры в настройках пользователя, от имени которого
будет вестись работа с ККМ.

Для этого необходимо зайти в меню Сервис -- Настройка пользователя (путь
указан для полного интерфейса)

![C:\\Users\\krut8_000\\AppData\\Local\\Microsoft\\Windows\\INetCacheContent.Word\\2017-01-09_21-57-32.png](/images/image15.png)

В разделе «Розничная торговля и торговое оборудование» необходимо
установить следующие параметры:

[Основная касса ККМ] -- необходимо выбрать ту кассу, которая
была указана в настройках подключения торгового оборудования.

[Пароль администратора фискального регистратора] -- Пароль,
с которым будут производиться операция «Закрытие смены» (Снятие
Z-отчета). Возможные значения:

29- Администратор, 30 - Системный администратор

[Пароль кассира фискального регистратора] -- пароль, с
которым будут производиться операции пробития чеков. Возможные значения:
1,2,3,...,28. Для разделения разных пользователей 1С по разным
пользователям ККМ можно указать разные значения пароля кассира для этих
пользователей.

[Печать НДС в кассовых чеках из документов «Чек ККМ»] -
включение параметра позволяет отражать налоговые ставки и суммы в чеках.
