# Исправление марок, записанных в документ «Чек ККМ»

Если в табличной части кодов маркировки документа «Чек ККМ» сохранились коды,
содержащие служебный символ-разделитель `GS` (символ с кодом 29), их можно
массово исправить с помощью типовой обработки «Универсальный подбор и обработка
объектов».

## Порядок действий

1. Открыть обработку «Универсальный подбор и обработка объектов» через меню
   **Файл → Открыть**.

2. В обработке выбрать объект поиска «ЧекККМ» и добавить условие:

   > `КАС_ШтрихкодыМаркировкиКоличествоСтрок` больше `0`

![Настройка условия отбора документов](/images/marking-fix/c023e18b546e128efe7fa7788224cb36.png)

3. Если количество найденных объектов будет не нулевым, то такие документы
   отобразятся на закладке «Найденные объекты».

4. Перейти на закладку «Обработки» и дважды щёлкнуть левой кнопкой мыши по пункту
   «Произвольный алгоритм».

5. Задать наименование алгоритма `ЗаменаСимволаGS`, а в текст алгоритма записать
   следующий код:

```bsl
ТЧМарки = Объект.КАС_ШтрихкодыМаркировки;

Для Каждого Марки Из ТЧМарки Цикл

    ШтрихкодМаркиВрем = Марки.ШтрихкодМарки;

    Если Найти(ШтрихкодМаркиВрем, Символ(29)) > 0 Тогда
        Марки.ШтрихкодМарки = СтрЗаменить(ШтрихкодМаркиВрем, Символ(29), "");
        Объект.Записать();
    КонецЕсли;

КонецЦикла;
```

![Текст произвольного алгоритма](/images/marking-fix/cbe3b12f9880761727d6582b12699a7e.png)

6. Нажать кнопку «Выполнить».

В результате все марки, записанные в документ и содержащие символ `GS`, будут
перезаписаны без этого символа.
