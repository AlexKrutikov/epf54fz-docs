# Доработка конфигурации №1 — передача ссылки на документ печати чека

::: warning Внимание
Если ранее данная доработка уже проводилась при использовании более ранних
релизов обработки, то повторно делать эту доработку при обновлении обработки
не требуется!
:::

Цель данной доработки — это передача в обработку печати чека ссылки на документ,
из которого вызвали эту печать. В стандартных механизмах пробития чека ссылка на
документ не передаётся, что делает невозможным получение из пробиваемой
конфигурации расширенной информации по товарным позициям и способам расчёта.
Указанная далее доработка позволяет решить эту проблему.

Начиная с релиза ФЗ.54.07 обработки обслуживания ККМ присутствует возможность
получать ссылку на документ, из которого происходит оплата, путём передачи её из
конфигурации в качестве параметра функции `ОткрытьЧек()`. В модуле обработки в
функции `ОткрытьЧек()` уже встроен механизм обработки этого передаваемого
параметра. Ниже приведён порядок действий по доработке конфигурации для
обеспечения бесперебойного механизма пробития кассовых чеков.

## 1. Включить возможность редактирования конфигурации

Зайти в конфигуратор. Открыть меню *Конфигурация → Поддержка → Настройка
поддержки* и нажать на кнопку «Включить возможность изменения».

![Настройка поддержки](/images/print-link/148fd20b429e8c6c80b11b2732538564.png)

![Кнопка «Включить возможность изменения»](/images/print-link/76b7992afe16b264080b19d2aba2977f.png)

*Если данная кнопка не отображается, то значит в вашей конфигурации уже разрешено
редактирование и можно переходить к следующему пункту.*

В следующем окне **нажимаем «Да»** в ответ на предупреждение:

![Предупреждение](/images/print-link/3036a9530c9598b82fb100e34abb5bff.png)

В настройках правил поддержки устанавливаем следующие настройки и **нажимаем «ОК»**:

![Правила поддержки](/images/print-link/da75644443cc5ecf75920a269eaeb3a0.png)

Закрываем окно настройки поддержки.

![Окно настройки поддержки](/images/print-link/a39879bcc69f41ee383284673247279e.png)

## 3. Доработка документов «Приходный кассовый ордер» и «Расходный кассовый ордер»

В дереве конфигурации в разделе «Документы» находим документ «Приходный кассовый
ордер», раскрываем список форм и открываем форму документа.

![Формы документа ПКО](/images/print-link/6c9ec64429e9b33922e3d28af529378a.png)

В открывшейся форме документа переходим на закладку «Модуль», а в нём — в
процедуру `ОсновныеДействияФормыЧек()`.

![Модуль формы документа](/images/print-link/d74e00335e2574ec4969c2cc1dec40fd.png)

В модуле находим такой текст:

```bsl
Результат = ПолучитьСерверТО().ПечатьЧекаПКО(ФР,
    "",
    НомерЧекаККМ,
    НомерСмены,
    ТаблицаПлатежей,
    СуммаДокумента,
    0);
```

![Исходный вызов ПечатьЧекаПКО](/images/print-link/3eb4514042020450354161facc4e8a68.png)

Перед строкой `Результат = ПолучитьСерверТО().ПечатьЧекаПКО(ФР, …` вставить текст
**(этот текст одинаков для вставки во все документы)**:

```bsl
//Доработка для онлайн-касс
ДопПараметры = Новый Структура;
ДопПараметры.Вставить("ДокументСсылка", Ссылка);
//\\Конец доработки для онлайн-касс.
```

В сам вызов процедуры `ПолучитьСерверТО().ПечатьЧекаПКО()` добавить 8-й параметр
`ДопПараметры` **(привести в соответствие с рисунком)**. Должно получиться так:

```bsl
Результат = ПолучитьСерверТО().ПечатьЧекаПКО(ФР,
    "",
    НомерЧекаККМ,
    НомерСмены,
    ТаблицаПлатежей,
    СуммаДокумента,
    0,
    ДопПараметры);  //доработка для онлайн-касс
```

::: warning
Данный текст лучше не копировать поверх старого, поскольку в разных конфигурациях
реквизиты могут называться по-разному.
:::

Для документа **«Расходный кассовый ордер»** сделать такие же доработки в модуле
формы документа. Текст вставляем перед строкой
`Результат = ПолучитьСерверТО().ПечатьЧекаРКО(ФР, …` и добавляем 8-й параметр в
вызов процедуры **(см. рисунок ниже)**.

![Доработка формы РКО](/images/print-link/c7419c2d3768807d5b7618119d8386b2.png)

Должно получиться так:

```bsl
//Доработка для онлайн-касс
ДопПараметры = Новый Структура;
ДопПараметры.Вставить("ДокументСсылка", Ссылка);
//\\Конец доработки для онлайн-касс

Результат = ПолучитьСерверТО().ПечатьЧекаРКО(ФР,
    "",
    НомерЧекаККМ,
    НомерСмены,
    ТаблицаПлатежей,
    СуммаДокумента,
    0,
    ДопПараметры); //доработка для онлайн-касс
```

::: warning
Данный текст лучше не копировать поверх старого, поскольку в разных конфигурациях
реквизиты могут называться по-разному.
:::

## 4. Доработка документа «Оплата от покупателя платёжной картой»

Если в конфигурации присутствует и используется данный документ, то, как и в
предыдущем примере, необходимо перейти в модуль формы данного документа в
процедуру `ОсновныеДействияФормыЧек()` и привести модуль к следующему виду:

![Доработка формы ОПК](/images/print-link/24ebb3a3b6a68312af0d2b4e0a999ae8.png)

Текст должен получиться примерно такой:

```bsl
//Доработка для онлайн-касс
ДопПараметры = Новый Структура;
ДопПараметры.Вставить("ДокументСсылка", Ссылка);
//\\Конец доработки для онлайн-касс

Если ВидОперации = Перечисления.ВидыОперацийОплатаОтПокупателяПлатежнойКартой.ОплатаПокупателя Тогда

    Результат = ПолучитьСерверТО().ПечатьЧекаПКО(ФР,
        "",
        НомерЧекаККМ,
        НомерСмены,
        ТаблицаПлатежей,
        0,
        СуммаДокумента,
        ДопПараметры); // доработка для онлайн-касс

Иначе

    Результат = ПолучитьСерверТО().ПечатьЧекаРКО(ФР,
        "",
        НомерЧекаККМ,
        НомерСмены,
        ТаблицаПлатежей,
        0,
        СуммаДокумента,
        ДопПараметры); //доработка для онлайн-касс

КонецЕсли;
```

::: warning
Данный текст лучше не копировать поверх старого, поскольку в разных конфигурациях
реквизиты могут называться по-разному.
:::

## 5. Доработка документа «Чек ККМ»

Если предполагается пробитие чеков из документа «Чек ККМ» (например, из режима
РМК или стандартной формы документа), то необходимо в модуле документа найти
функцию `ПровестиИРаспечататьЧек()`.

В данной процедуре нужно найти строку вида:

```bsl
ОшибкаТО = ПолучитьСерверТО().ПечатьЧека(ФР, ПолучитьСерверТО().ПолучитьПарольКассираККМ(), НомерЧекаККМ, НомерСменыККМ,
    ТаблицаТоваров, ПолучитьСуммуНаличнойОплаты(),
    ПолучитьСуммуБезналичнойОплаты(),
    ВидОперации = Перечисления.ВидыОперацийЧекККМ.Возврат)
```

В последних релизах конфигурации эта строка может иметь следующий вид (отличие в
один параметр `ДопДанные`):

```bsl
ОшибкаТО = ПолучитьСерверТО().ПечатьЧека(ФУ, ПолучитьСерверТО().ПолучитьПарольКассираККМ(), НомерЧекаККМ, НомерСменыККМ,
    ТаблицаТоваров, ПолучитьСуммуНаличнойОплаты(),
    ПолучитьСуммуБезналичнойОплаты(),
    ВидОперации = Перечисления.ВидыОперацийЧекККМ.Возврат, ДопДанные);
```

Произвести доработку данной строки следующим образом. Перед вызовом функции
`СерверТО.ПечатьЧека` добавить строки:

```bsl
//Доработка для онлайн-касс
ДопПараметры = Новый Структура;
ДопПараметры.Вставить("ДокументСсылка", Ссылка);
//\\Конец доработки для онлайн-касс.
```

И добавить параметр `ДопПараметры` последним параметром для данной функции.
В итоге должно получиться как на скриншотах ниже:

![Доработка ЧекККМ](/images/print-link/069065884a2510a9746b906bdae6862d.png)

Для последних релизов конфигураций вид будет следующим:

![Доработка ЧекККМ (новые релизы)](/images/print-link/0c0686e860cf3b088c1d257a001da678.png)

Далее переходим в модуль обработки «ТОСервер».

![Модуль ТОСервер](/images/print-link/eceb67be21875d3781a9b221fa28e442.png)

Находим функцию `ПечатьЧека` и добавляем в ней новый параметр
`ДопПараметры = Неопределено`, а также добавляем **7-й (седьмой)** параметр
`ДопПараметры` в вызов функции `Обработка.ОткрытьЧек` (в старых релизах там по
умолчанию может передаваться всего 5 параметров, поэтому 6-й параметр оставляем
пустым, а `ДопПараметры` добавляем именно седьмым по очереди).

![Доработка ПечатьЧека в ТОСервер](/images/print-link/1a0423e8db76907c3cef20ee93632458.png)

В новых релизах вид будет немного другим:

![Доработка ПечатьЧека (новые релизы)](/images/print-link/d6237ef23362d83d185ae53190517af3.png)

На скриншоте видно, что в последних релизах конфигураций передаётся и 6-й
параметр, поэтому здесь добавлять его пустым нет необходимости.

:::
